# Data Visualization Methods

A practice project exploring different plotting styles and Python libraries
for data visualization, applied to a company sales dataset.

## What's inside
- `data_vis_practice.ipynb`: the notebook with all the plots and code
- `company_sales_data.csv`: the company sales dataset used for the examples

## What it covers
- Common plot types: line, bar, scatter, histogram, pie [edit to match your notebook]
- Customizing plots: titles, labels, colors, legends, styles
- Using popular Python libraries such as Matplotlib and Seaborn
- Built-in sample datasets such as `tips` and `fmri` for extra practice

## Libraries used
Python, pandas, Matplotlib, Seaborn

## How to run
1. Clone the repo: `git clone https://github.com/prggr8/Data_visualization_methods.git`
2. Install the libraries: `pip install pandas matplotlib seaborn jupyter`
3. Open `data_vis_practice.ipynb` in Jupyter and run the cells in order
